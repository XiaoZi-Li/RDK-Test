# 机器狗远程监控与运动控制上位机软件 V1.0

面向四足机器狗（PuppyPi / RDK X5 板端系统）的 PC 端远程监控与控制软件，
基于 PySide6（Qt 6）开发，提供组件状态监控、多路视频墙、运动控制、
大模型对话控制、避障监测、日志查看与系统管理等功能的图形化操作界面。

## 功能特性

| 功能模块 | 说明 |
|---|---|
| 系统总览 | 板端组件运行状态灯、UDP 端口监听状态、视频流在线状态、快捷启停操作 |
| 视频监控 | 右眼/左眼/深度伪彩图/YOLO 检测/手势识别 五路实时视频墙，双击放大单路 |
| 运动控制 | 8 个离散动作按钮（长按持续运动 + 0.2s 心跳）、WASD 键盘控制、连续遥控速度滑杆 |
| 对话控制 | 自然语言指令解析为动作序列自动执行，视觉问句自动路由至视觉问答，支持喇叭播报 |
| 避障监测 | 自动巡航开关、避障状态机阶段、三区距离/近像素占比、方位判定与 USB 语义检测 |
| 日志中心 | 板端 7 类组件日志查看，支持手动/自动刷新 |
| 系统管理 | 全部组件启动/停止/重启，双目深度链路与运动中枢单独重启 |
| 演示模式 | 内置模拟数据源（含合成视频画面），无需连接真实板端即可完整体验全部功能 |

## 运行环境

- 操作系统: Windows 10/11、Ubuntu 20.04+（其他支持 Qt 6 的桌面系统亦可）
- Python: 3.10 及以上
- 依赖: PySide6 >= 6.6（唯一第三方依赖，网络层全部基于 Python 标准库）

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2a. 演示模式启动（无需板端，内置模拟数据）
python main.py --demo

# 2b. 连接真实板端启动
python main.py --host 192.168.1.10
```

连接真实板端的前提：板端 `integrated_system/dashboard.py` HTTP 服务已启动
（默认端口 8081），且 PC 与板端处于同一局域网。

## 连接设置

软件内点击右上角"连接设置"可修改：

- 板端 IP 地址与 API 端口
- 状态轮询间隔（默认 3 秒）
- 长按心跳间隔（默认 200 毫秒）
- 遥控发送频率（默认 8 Hz）
- 演示模式开关

配置持久化保存在 `~/.puppy_console.json`。

## 打包为独立桌面应用（Windows）

```bat
pip install pyinstaller
pyinstaller --noconsole --onefile --name "机器狗上位机V1.0" main.py
```

生成的可执行文件位于 `dist/` 目录，可脱离 Python 环境直接运行。

## 目录结构

```
pc_console/
├── main.py                  # 程序入口
├── requirements.txt         # 依赖清单
├── app/
│   ├── version.py           # 软件名称与版本信息
│   ├── config.py            # 连接配置管理（持久化）
│   ├── core/                # 核心业务
│   │   ├── models.py        #   状态数据模型
│   │   ├── workers.py       #   后台任务与状态轮询线程
│   │   ├── session.py       #   板端会话（在线/演示统一封装）
│   │   └── simulator.py     #   演示模式模拟数据源
│   ├── net/                 # 网络通信
│   │   ├── api_client.py    #   板端 HTTP API 客户端
│   │   └── mjpeg_client.py  #   MJPEG 视频流接收线程
│   └── ui/                  # 界面
│       ├── theme.py         #   QSS 暗色主题
│       ├── widgets.py       #   通用部件（卡片/状态灯/提示条）
│       ├── video_widget.py  #   单路视频画面控件
│       ├── main_window.py   #   主窗口（导航/页面堆栈/状态栏）
│       ├── settings_dialog.py # 连接设置对话框
│       └── pages/           #   七个功能页面
├── tools/
│   ├── capture_screenshots.py  # 手册截图采集脚本
│   └── generate_materials.py   # 软著申报材料生成脚本
└── screenshots/             # 界面截图（演示模式采集）
```
