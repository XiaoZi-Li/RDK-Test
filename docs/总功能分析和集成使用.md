## 1. 项目概述

### 1.1 项目定位
这是一个基于**地平线 RDK X5** 开发板的**四足机器狗控制系统**，集成了：
- AI视觉推理（BPU加速）
- 机器人控制（ROS2）
- 多媒体处理（编解码/OSD）
- 硬件接口（GPIO/I2C/SPI/UART）

### 1.2 核心技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 硬件 | RDK X5 / X3 | 地平线AI开发板 |
| 加速 | BPU | 深度学习加速器 |
| 框架 | ROS2 Humble | 机器人操作系统 |
| AI模型 | YOLOv5/FCOS/UNet | 目标检测/分割 |
| 视觉库 | OpenCV | 图像处理 |
| 控制 | PuppyPi SDK | 机器狗控制 |

### 1.3 代码规模
| 目录 | 文件数 | 主要语言 |
|------|--------|----------|
| 40pin_samples | 11 | Python |
| cdev_demo | 20+ | C++ |
| multimedia_samples | 50+ | C |
| pydev_demo | 30+ | Python |
| puppy_ws | 20+ | Python |
| **总计** | **130+** | - |

## 4. 集成使用方案

### 4.1 方案一：纯视觉AI应用

**适用场景**: 只需要AI目标检测/分类/分割，不需要机器人控制

**使用的模块**:


## 6. 场景化应用指南

### 6.1 场景1: 智能跟随机器人

**目标**: 机器人跟随人体移动

**实现方案**:
```bash
# 使用 puppy_ws 的跟随模式
ros2 launch puppy_brain follow_only.launch.py
```

**关键参数调整** (在 `full_system.launch.py` 中):
```python
# perception_node
'score_threshold': 0.25,        # 置信度阈值

# decision_node
'follow_area_near_stop': 0.42,   # 太近停止
'follow_area_far_walk': 0.10,   # 太远行走
'turn_gain': 0.85,              # 转向灵敏度
'control_smooth_alpha': 0.28,   # 平滑系数
```

**调参技巧**:
| 问题 | 解决方案 |
|------|----------|
| 机器人离人太近不停 | 减小 `follow_area_near_stop` (如0.35) |
| 机器人离人太远不走 | 增大 `follow_area_far_walk` (如0.15) |
| 转向抖动 | 减小 `control_smooth_alpha` (如0.15) |
| 响应太慢 | 增大 `control_smooth_alpha` (如0.45) |

### 6.4 场景4: 区域入侵检测

**目标**: 检测目标进入指定区域

**实现方案**:
```python
# 在 perception_node 或独立节点中添加
def check_roi_violation(bbox, roi):
    """检查是否入侵区域"""
    x1, y1, x2, y2 = bbox
    rx1, ry1, rx2, ry2 = roi

    # 计算重叠区域
    overlap_x = max(0, min(x2, rx2) - max(x1, rx1))
    overlap_y = max(0, min(y2, ry2) - max(y1, ry1))
    overlap_area = overlap_x * overlap_y

    bbox_area = (x2 - x1) * (y2 - y1)

    # 如果重叠面积超过50%，认为入侵
    return overlap_area / bbox_area > 0.5
```

## 7. 扩展开发指南

### 7.1 添加新的ROS2节点

**步骤1: 创建节点文件**
```python
# /app/puppy_ws/src/puppy_brain/puppy_brain/my_node.py
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class MyNode(Node):
    def __init__(self):
        super().__init__('my_node')
        self.pub = self.create_publisher(String, '/my_topic', 10)
        self.sub = self.create_subscription(
            String, '/other_topic', self.callback, 10)

    def callback(self, msg):
        self.get_logger().info(f'Received: {msg.data}')

def main(args=None):
    rclpy.init(args=args)
    node = MyNode()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

**步骤2: 修改 setup.py**
```python
# setup.py 中添加
entry_points={
    'console_scripts': [
        'my_node = puppy_brain.my_node:main',
    ],
}
```

**步骤3: 编译和运行**
```bash
colcon build
ros2 run puppy_brain my_node
```

## 8. 性能优化指南

### 8.1 AI推理性能

| 优化项 | 方法 | 效果 |
|--------|------|------|
| 减小输入尺寸 | `input_width/height` 调小 | FPS↑ 但精度↓ |
| 选择轻量模型 | YOLOv5s vs YOLOv5x | FPS↑ |
| 调整检测阈值 | 提高 `score_threshold` | 减少计算 |
| 减小 `nms_top_k` | 限制检测数量 | FPS↑ |

### 8.2 推荐配置

**高FPS场景** (60+ FPS):
```python
# YOLOv5s 320x320
models = dnn.load('yolov5s_320x320_nv12.bin')
score_threshold = 0.4
nms_top_k = 10
```

**高精度场景**:
```python
# YOLOv5x 672x672
models = dnn.load('yolov5x_672x672_nv12.bin')
score_threshold = 0.25
nms_top_k = 50
```

## 9. 故障排查手册

### 9.1 常见错误码

| 错误 | 可能原因 | 解决方案 |
|------|---------|----------|
| `ModuleNotFoundError` | Python库未安装 | `pip3 install hobot-dnn-rdkx5` |
| `load model failed` | 模型文件不存在 | 检查 `/app/model/basic/*.bin` |
| `Camera open failed` | 摄像头被占用 | `killall mipi_cam` |
| `colcon build failed` | 依赖缺失 | `apt install python3-colcon-*` |
| `No module named 'rclpy'` | ROS2环境未加载 | `source /opt/tros/humble/setup.bash` |

### 9.2 调试命令

```bash
# 查看运行中的节点
ros2 node list

# 查看话题带宽
ros2 topic hz /perception/result_json

# 查看节点间连接
ros2 topic info /perception/result_json

# 查看参数
ros2 param list

# 设置参数 (临时)
ros2 param set /perception_node score_threshold 0.2

# 查看日志
ros2 run rqt_logger_level rqt_logger_level
```
