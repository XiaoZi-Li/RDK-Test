> 更新日期：2026-08-10　|　当前版本：commit `465c9ce`

> 适用场景：参赛外地演示（手机热点网络）

## 一、项目概述

基于地瓜机器人 RDK X5 开发板的智能机器狗，具备四大能力：

| 能力 | 实现方式 | 说明 |
|------|---------|------|
| 双目深度避障 | GS130W 双目相机 + BPU stereonet | 深度图实时分析前方障碍，自主转向/停止 |
| 语音交互 | 本地 VAD/ASR + 云端 LLM + 本地 TTS | 唤醒词"小狗"，支持对话和多动作序列控制 |
| 视觉问答 | USB 摄像头取帧 + 硅基流动 VLM | "你能看到什么"→ 拍照 → 大模型描述 → 喇叭播报 |
| 手势控制 | USB 摄像头 + MediaPipe Hands | 手掌=前进、拳头=趴下、点赞=坐下、OK=后退、V=左转、双掌=右转 |
| Web 监控 | 板端 HTTP 服务 | 完整面板/轻量面板/双目页面/手势画面 |

**运动控制优先级（硬约束）：避障 > 语音 > 手势**，由 `motion_arbiter.py` 统一仲裁。

## 二、硬件平台

- **主控**：RDK X5（Bayes-e BPU，10 INT8 TOPS，4/8GB RAM，Ubuntu 22.04，TROS Humble）
- **双目相机**：GS130W（MIPI 接口，物理倒装 180°，上半=右眼、下半=左眼）
- **USB 摄像头**：手势识别 + 视觉问答共用（/dev/video0）
- **音频**：USB 声卡麦克风（plughw:1,0）+ 喇叭（plughw:0,0）
- **底盘**：UART 运动中枢 sit.py（UDP 5006 接收指令）

## 三、系统架构（双版本，互斥运行）

### 完整版（全功能，参赛演示用）

启动：`/app/integrated_system/start_all.sh start`

```
mipi_cam(双目) → stereonet(BPU深度) → 避障节点 ─┐
                    ↓                            │
              3路 mjpeg_bridge                   ├──→ motion_arbiter(:5005) → sit.py(:5006) → 底盘
USB摄像头 → gesture_control.py(:8094推流) ──────┤         ↑
麦克风 → voice_assistant.py(VAD→ASR→LLM/VLM→TTS) ┘    PC遥控/面板
```

### 轻量版（省 CPU，无视频流）

启动：`/app/integrated_system/start_all_lite.sh start`
裁剪：codec / websocket / 5路MJPEG / AI叠加 / 手势推流。实测 CPU ~43%。

### 双目拍摄标定工具（独立第三套，与前两套互斥）

启动：`/app/gs130w_stereo/scripts/start_capture.sh start` → 网页 `http://<板端IP>:8095`
用途：**只拍左右眼图，不起深度/避障**。点"拍摄"存 4 文件（raw=深度算法输入方向 + view=人眼方向），
拍完在网页上给每张标定正确决策（左转/右转/直行）→ `labels.csv`，供离线深度计算矫正避障判断。
存图目录默认 `/app/stereo_captures`（可用 `CAP_DIR` 环境变量改）。

### 端口一览（完整版）

| 端口 | 服务 | 用途 |
|------|------|------|
| 5005/udp | motion_arbiter | 控制指令入口（仲裁） |
| 5006/udp | sit.py | 运动中枢 |
| 8081 | dashboard.py | 完整监控面板（5路视频+控制+LLM对话） |
| 8090 | http.server | 双目页面：view.html / view_status.html（含障碍物方位） |
| 8071/8072 | mjpeg_bridge | 右眼/左眼图像 |
| 8073 | mjpeg_bridge | 深度图 |
| 8074 | status_bridge | 避障状态 JSON（/status） |
| 8094 | gesture_control | 手势画面（/stream 流，/snapshot 单帧） |
| 8082 | dashboard_lite.py | 轻量面板（仅轻量版） |
| 8095 | stereo_capture.py | 双目拍摄标定工具（仅拍摄模式） |

## 四、关键设计决策（不要轻易改）

1. **双目图像方向**：相机物理倒装 180°，修正只在**推流显示层**（mjpeg_bridge `--vflip --hflip` + 区域交换 8071←top 8072←bottom）。**绝不能改 `mipi_rotation`**——stereonet 匹配依赖原始方向，避障节点已用 `depth[::-1,::-1]` 补偿。
2. **深度链路**：mipi_cam 默认不发 camera_info，由 `camera_info_publisher.py`（TRANSIENT_LOCAL）补发。**stereonet 启动不稳定是已知老问题**，不出图时重启双目即可（`start_all.sh restart-stereo`）。
3. **两版文件隔离**：轻量版全部是独立新文件（`_lite` 后缀），完整版文件保持原样，不要互相混入。
4. **视觉取帧**：视觉问答从 `:8094/snapshot` 取帧（复用手势进程的摄像头），**不要再打开 /dev/video0**，会冲突。
5. **沙箱坑**：Trae 沙箱注入旧 libstdc++ 会让 vosk/rclpy 加载失败、/root/.ros 不可写会让 ROS 启动失败——start_all.sh 已内置清理，**手动重启进程时必须清理 LD_LIBRARY_PATH 中的 trae-cn-server 路径**（用 `launch_bg` 同等逻辑）。
6. **config.json 已被 gitignore**（含 API 密钥，不进仓库），配置模板在 `config.example.json`。

## 五、换网络（手机热点）后如何恢复 SSH 连接

热点下板子 IP 会变（上次变为 `192.168.43.28`）。**板端所有服务都绑在 0.0.0.0/127.0.0.1，换网络后板端无需任何改动**，只需重新找到 IP 并更新电脑端连接。

### 步骤 1：让板子和电脑连上同一热点

- 手机开热点（建议提前在家测试过一次，让板子记住热点密码）。
- 板子连热点的方式（任选）：
  - **提前配置**：在家用 `nmtui` 或 `nmcli` 把热点加为已知网络并设自动连接：
    ```bash
    nmcli connection add type wifi con-name "hotspot" ssid "你的热点名" \
      wifi-sec.key-mgmt wpa-psk wifi-sec.psk "热点密码" connection.autoconnect yes
    ```
  - 若到现场才发现连不上：用**串口线**或 **USB Type-C 直连**进系统再配。

### 步骤 2：查板子的新 IP（任选其一）

1. **手机热点管理页**（最方便）：热点设置 → 已连接设备列表，找到板子设备名/IP（如 192.168.43.28）。
2. **串口/直连终端**里执行：`hostname -I` 或 `ip -4 addr show wlan0`。
3. 电脑端扫描（同连热点）：`arp-scan -l` 或手机 App（如 Fing）。

### 步骤 3：更新 Trae IDE 的 SSH 配置

1. 打开电脑端 SSH 配置：`~/.ssh/config`（Trae 远程资源管理器里也有"编辑 SSH 配置"入口）。
2. 把原来的 Host 改成新 IP，**建议保留两组**，家里/现场一键切换：
   ```
   Host rdkx5-home
       HostName 192.168.1.4
       User root

   Host rdkx5-hotspot
       HostName 192.168.43.28
       User root
   ```
3. Trae → 远程 SSH → 选 `rdkx5-hotspot` 连接，打开 `/app` 工作区即可继续开发。
4. 浏览器访问面板同理，只换 IP：`http://192.168.43.28:8081`（完整面板）、`http://192.168.43.28:8090/view_status.html`（双目避障页）、`http://192.168.43.28:8094`（手势画面）。

### 步骤 4（可选）：固定 IP 免去每次查找

热点网段一般是 192.168.43.x，可给板子设静态 IP（用 nmcli，对热点连接生效）：
```bash
nmcli connection modify "hotspot" ipv4.method manual \
  ipv4.addresses 192.168.43.28/24 ipv4.gateway 192.168.43.1 ipv4.dns "223.5.5.5"
nmcli connection up "hotspot"
```
> 注意：不同手机热点网段可能不同（有的是 192.168.43.x，有的是 172.20.10.x/苹果），设置前先用步骤 2 确认网段。

### 备用通道（完全无网/连不上时）

- **USB Type-C 直连**：电脑网卡会出现新接口，板端固定在内网段（X5 默认 `192.168.127.10`，电脑手动配同段静态 IP 如 192.168.127.100），然后 SSH 连该 IP。
- **串口**：115200 波特率进控制台，可执行一切网络配置。

## 六、常用运维命令

```bash
# 完整版
/app/integrated_system/start_all.sh start|stop|status|restart-stereo|restart-robot
# 轻量版
/app/integrated_system/start_all_lite.sh start|stop|status
# 双目拍摄标定工具（与上面两套互斥，会先杀掉双目/避障进程）
/app/gs130w_stereo/scripts/start_capture.sh start|stop|status|logs
# 步态现场微调（不改代码，重启生效；默认已恢复出厂值 z=8/swing=0.25/overlap=0.15）
GAIT_Z_CLEARANCE=8 GAIT_SWING_TIME=0.25 GAIT_OVERLAP_TIME=0.15 /app/integrated_system/start_all.sh restart-robot
# 日志（全部在 /tmp/integrated_system/）
tail -f /tmp/integrated_system/voice_assistant.log     # 语音
tail -f /tmp/integrated_system/gesture_control.log     # 手势
tail -f /tmp/gs130w_v2/avoidance.log                   # 避障
# 手动发运动指令（调试用）
echo '{"action":"stop","source":"debug"}' | nc -u -w1 127.0.0.1 5005
# 视觉问答模块单独测试
cd /app/integrated_system && python3 vision_assistant.py "你看到了什么"
```
